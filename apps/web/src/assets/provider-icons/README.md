# Provider icons

Monochrome brand SVGs vendored from [@lobehub/icons](https://github.com/lobehub/lobe-icons)
(MIT license, `icons-static-svg` v1.94.0). All use `fill="currentColor"` so they follow
the surrounding text color in both themes.

Brand logos identify the third-party service a provider config points at
(nominative use); they are trademarks of their respective owners.
